# baserom: your own discs

Put an image of each disc you own here. Everything in this directory except
this file is ignored by git, and nothing here is ever committed or shared
([docs/policy/SOURCING.md](../docs/policy/SOURCING.md)).

1. Dump your own discs to ISO images (any file names; `SCES_509.16.iso`,
   named after the serial, is the convention here).
2. Check and identify them:

   ```sh
   python3 tools/openrac.py discs          # size and SHA-1
   python3 tools/openrac.py discs --full   # every checksum below
   ```

3. Put each game's inputs where its build expects them:

   ```sh
   python3 tools/openrac.py setup               # every game you have a disc for
   python3 tools/openrac.py setup rac1/pal      # one version
   ```

   `setup` hard-links the image into the game's directory, reads the boot
   executable out of it (checked against its SHA-1), and links the game's
   toolchain path to [toolchains/](../toolchains/README.md). It never
   overwrites a file that is already there, and tells you the next command
   to run for each game.

These are the only versions OpenRAC supports. Images are recognised by the
executable `SYSTEM.CNF` boots, so a file name does not matter, but other
releases (Greatest Hits, other regions) have different checksums and are
reported as such.
