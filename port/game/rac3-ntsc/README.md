# openrac-rac3-ntsc: Up Your Arsenal, NTSC-U

Up Your Arsenal's NTSC-U disc (`SCUS_973.53`), built by [hostgen](../../tools/hostgen/README.md) from
[games/rac3](../../../games/rac3/decomp). rac3-decomp's C is PAL's; this program reads it renamed to
NTSC-U's addresses (`release_names.json`, from [release_rac3.py](../../tools/hostgen/release_rac3.py)).

Not playable yet: its `main` is not known (`entry` is null) and `libraries.tsv` is empty. The
menu (`frontbin`) is a group of its own; the online program (`i5bootn`) is left out.

| File | |
|---|---|
| `hostgen.json` | the game and how hostgen reads it ([port/game](../README.md#what-a-game-is)) |
| `libraries.tsv` | the library calls the port answers (none yet) |
| `release_names.json` | the NTSC-U names of rac3-decomp's PAL-named C (generated by release_rac3.py) |
