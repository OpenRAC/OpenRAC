# The OpenRAC mod SDK

The SDK lets you write a **native mod** for OpenRAC: a small shared library
that the game loads at start. A mod can use hook points, run code every game
tick, read the pad and have its own settings. The design and rules are in
[docs/port/MODS.md](https://github.com/OpenRAC/OpenRAC/blob/master/docs/port/MODS.md)
(`docs/MODS.md` in the archive). Example mods are in
[OpenRAC/openrac-mods](https://github.com/OpenRAC/openrac-mods).

Mods that only change textures, models or levels do not need the SDK. Make
them with the level editor
([editor/MODDING.md](https://github.com/OpenRAC/OpenRAC/blob/master/editor/MODDING.md)).

**New to modding? Start with [the guides](docs/README.md).**
[Getting started](docs/getting-started.md) goes from the template to a mod
that players install from your repository's link.

|---|---|

| [include/openrac/games/rac1.hpp](include/openrac/games/rac1.hpp) | the hook points as C++ types (generated) |
| [bindings/](bindings) | each game's hook points and fields; `<game>.ids.lock` keeps their ids |
| [cmake/](cmake/OpenRACModConfig.cmake) | `find_package(OpenRACMod)` and `openrac_add_mod()` |
| [template/](template) | a C++ mod to copy |
| [template-script/](template-script) | a Luau script mod to copy (no compiler needed) |
| [types/](types) | type definitions for script mods, for editor autocomplete |
| [examples/frame-counter/](examples/frame-counter) | a C mod that uses each part of the interface |
| [tests/](tests) | the C++ layer's test and the [manifest test cases](tests/manifests/README.md) |
| [catalogue/rac1/](catalogue/rac1/BEHAVIOUR.md) | Ratchet & Clank's moby classes and their update functions (experimental, generated) |
| [api/](api) | the recorded ABI (generated by [tools/gen_api_lock.py](tools/gen_api_lock.py); rows are only added), and `members.tsv` with each member's area, minor and status |
| [tools/package_mod.py](tools/package_mod.py) | checks the manifest and builds the mod's `.zip` |
| `tools/new_api.py`, `tools/bump_api.py` | for OpenRAC's own code: add a call, change the version ([MOD_API.md](https://github.com/OpenRAC/OpenRAC/blob/master/docs/port/MOD_API.md)) |

## Getting the SDK

Download `openrac-mod-sdk-<version>.zip` from the
[OpenRAC release](https://github.com/OpenRAC/OpenRAC/releases) named
`sdk-v<version>` and unpack it anywhere. You do not need a copy of OpenRAC.

The version is the interface's `MAJOR.MINOR` plus a patch number for SDK fixes.
A mod built with SDK 1.0.x works with every 1.y port. Each release lists the
archive's SHA-256, so a build can pin it (see openrac-mods' `sdk.lock` and
`tools/fetch_sdk.py`). Below, `<SDK>` is the unpacked folder, or `sdk/` in an
OpenRAC checkout. To build the archive from a checkout, run
`python3 sdk/tools/package_sdk.py`.

## License

Everything under `sdk/` uses the MIT license ([LICENSE](LICENSE)), so your mod
can use any license. The rest of OpenRAC, including the port that runs mods,
is GPL v3 or later. The templates start with the MIT license; replace it with
your own.

## Releases

Each SDK version is released as `sdk-v<version>` on OpenRAC/OpenRAC. SDK
releases are never marked Latest, because the launcher updates from the Latest
release and ignores releases that are not its own.
