# Games

One folder per game. Each looks the same:

```
games/<game>/
  README.md            the game, its versions (disc, serial, region), which decomp each comes from,
                       and where the port's code for it lives (port/game/<game>-<version>/)
  game.json            the discs, their checksums, which decomp each version is built from, its pin
  decomp/              our decomp of the game (git submodule): every version of it
  decomp-patches/      OpenRAC-only changes to decomp/: NNNN-<what>.patch, files/, README.md
```

Ratchet & Clank (rac1) also has `ntsc-decomp/` and `ntsc-decomp-patches/`: the third-party NTSC
decomp of the North American release, kept apart from ours.

A decomp is its own project: build and work on it from its own folder, following its own README
([docs/LAYOUT.md](../docs/LAYOUT.md)). How to check the decomps out, change a patch or move a pin:
[docs/SOURCES.md](../docs/SOURCES.md).

## Adding a version

1. Add the version to `games/<game>/game.json`: its serial, region, disc and boot checksums
   (`python3 tools/openrac.py discs --full` prints them for an image in `baserom/`), what it
   decompiles, and the inputs `setup` should place. A version built from the game's decomp says
   `"dir": "games/<game>/decomp"` and `"source": {"shared": "decomp", ...}`, a copy of the
   game's top-level `"decomp"` record.
2. A new game's decomp: `git submodule add --depth 1 <url> games/<game>/decomp`, with
   `shallow = true` and `ignore = dirty` in `.gitmodules` like the others, and its record in
   game.json's top-level `"decomp"` (`dir`, `name`, `repo`, `branch`, `license`, `commit`,
   `date`, `imported`).
3. Run `python3 tools/openrac.py tables` and commit, as `feat(<game>/<version>): ...`.
