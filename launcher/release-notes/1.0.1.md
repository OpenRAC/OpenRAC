## Highlights

- **Going Commando can be built and played from an installed launcher.** The launcher now downloads the game's source and builds it from your own disc (#276). Before this, an installed launcher had no Going Commando program and no way to make one, so its Play button asked for a rebuild over and over.
  - The first build takes a few minutes and needs a C compiler. On Linux it also needs SDL's development packages for X11, Wayland and audio; the README lists them.
  - Levels you already set up stay valid, so the launcher doesn't read them from the disc again.

## Fixes

### Launcher

- The launcher never offers a Rebuild that can't produce the game's program. If Play's program is missing and this platform can't build it, the page says the game needs a newer launcher instead of looping (#283).
- Going Commando is rebuilt when the launcher's own source changes, so an update doesn't leave an old build in use (#278).

### Going Commando and the port

- An easier Field of View slider, also kept in the pause menu (#272). The game's view tests now open wider up and down to match a wider Field of View (#277).
- Vulkan rendering is streamlined, and GPU crashes now leave diagnostics behind (#273).
- HDR output allows higher brightness limits (#282).
- Interior lighting environments can be authored for the enhanced lighting (#281).
