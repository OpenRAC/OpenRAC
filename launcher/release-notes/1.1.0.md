## Highlights

- **Going Commando on every disc.** The PAL and USA v2.00 discs play alongside USA v1.01, and Going Commando ships prebuilt for all three (#341, #401, #405, #511, #538, #549, #561).
- **Going Commando on Android**, its assembly built from the disc on the device (#300, #310, #320).
- **Going Commando builds on Windows with a carried compiler**, and the launcher installs missing Windows build dependencies (#326, #514).
- **A Metal renderer for macOS**, offered in Settings (#370, #382).
- **iPhone and iPad**: the shared launcher with local disc import (#376, #377).
- **Rumble** from the game's own motor commands (#362).
- **Texture packs**: native PCSX2 packs, and SVG and KTX2 pictures kept compressed on the GPU (#443, #506, #526).
- **Mod SDK 1.20.0**: one mod for several games, Going Commando hook points, mod settings and save data, collision queries and a developer menu (#385, #460, #487, #489, #569).

## Mod SDK

- One mod can serve several games, with Going Commando's first hook points (#385).
- Going Commando hook points: item grants and givers, item equip, nanotech orbs, NG++ and vendors, on every disc (#387, #390, #414, #415, #466, #472).
- Ratchet & Clank hook points: the weapons' target choice, the vendor's menu, unspent gold bolts and the Gadgetron icon strip (#422, #444, #464, #535).
- Any mod can turn the hero's joints (#384), and a prop can be fixed to a moby's joint (#547).
- **Mod SDK 1.20.0** is released with this launcher.
- Interfaces 1.15 to 1.20: mod settings, mod data kept with the game's saves, the game's collision query, joint props, switches and choices in a mod's developer menu, and native mods opting in to Vulkan access (#460, #487, #489, #547, #569, #582).
- A native library other users can change is refused (#478, #493).
