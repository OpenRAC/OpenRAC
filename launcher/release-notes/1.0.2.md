## Fixes

### Going Commando on Windows

- **Going Commando builds again on Windows.** Launcher 1.0.1 gave the build its bundled Python in a form Windows' command prompt can't start (`\\?\D:\...\python.exe`), so the build stopped with "The system cannot find the path specified". The launcher and the build now use the plain path, and a build that already failed this way is set right when you build again (#294).
- Installations in long folders build in a short temporary folder and the finished program is copied back, so the build no longer stops on Windows' path length limit (#291).

### Launcher

- Development builds no longer offer the same launcher update over and over after a release (#293).
